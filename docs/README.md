# Yuga Live Components Documentation

Yuga Live Components (YLC) adds server-rendered reactive components to Yuga. State and actions live in PHP while the browser runtime synchronizes state, performs requests, morphs HTML, handles partial fragments, and exposes a JavaScript API.
